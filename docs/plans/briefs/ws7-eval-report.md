## Recommendation for plan decision #3 ("should STRUCTURED candidates skip the model?")

**Yes, conditionally — flip the default to skip when the deterministic mapping is complete.** On the 7 STRUCTURED
fixtures the model reproduced `SchemaOrgRecipeMapper` verbatim in 6/7 (Jaccard 1.00; the 7th is identical text that a
parser bug on decimal quantities corrupts on both paths) while costing 11–32 s per recipe here (longer on a phone). Where
it deviated it regressed as often as it improved: it fabricated a prep 30 / cook 30 split from "total 30 min"
(bbcgoodfood), merged one HowToSection step and invented notes from "(Note 2)" markers (recipetineats), and improved
exactly one page — Nigella's microdata, whose instructions are a single blob that the model split into 11 steps.

Proposed branch in `ExtractionViewModel`: for `CandidateSource.STRUCTURED`, compute `config.fallback(candidate, snapshot)`
first; if `ingredients.size >= 3 && steps.size >= 2`, save it immediately (instant, deterministic) and offer "Tidy up with
AI" on demand; otherwise (steps ≤ 1 or no ingredients) run the model as today. TEXT and whole-page candidates keep going
through the model, with a `NO RECIPE` refusal line added to the prompt so list pages stop producing invented recipes
(`list_pinchofyum_recipes`). Details, bugs and patches: `ws7-report.md`.
