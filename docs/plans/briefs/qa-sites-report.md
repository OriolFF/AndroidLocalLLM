## Method

Library → Open browser → type URL → wait for FAB → tap → detail, then diff the saved Room row (`run-as … cat databases/recipekeeper.db*` + host `sqlite3`) against the source. **Source of truth for the comparison:** the JSON-LD `Recipe` node (and, for non-JSON-LD pages, the visible ingredient/step text) in the page HTML. Many big sites answer `curl` with 403 (Cloudflare: Sally's, Budget Bytes, Serious Eats, Sip & Feast, Chefkoch); the WebView loads all of them, so for those I dumped the DOM the WebView itself rendered (`Runtime.evaluate document.documentElement.outerHTML` via `webview_devtools_remote_<pid>`) — independent of the app's own capture.

Timing note: my first detail-detector matched the extraction screen, so the early timings were wrong; after fixing it the figures below are real tap→detail times for the runs that were timed with the fixed detector. Structured pages that skip the model were observed on the detail already at +2.5 s screenshots (≤ 4 s). Text/JSON-LD-incomplete runs that used the model on this host took 17 s (receptes.cat, 680 tokens), 80 s (joyofbaking, ~1.1k tokens) and ~105 s (Nigella, 1,483 tokens) — much slower than WS12's 7–14 s; the host was not otherwise loaded (qemu at ~300 % CPU), so LiteRT-LM CPU throughput here is highly variable. Smitten (607 tokens) and Directo al Paladar (1,033 tokens) were not timed (detector bug).

## Systematic defects, ranked

1. **(P1) Hot-linked / bot-protected image CDNs fail silently → recipes saved without a picture.** Chefkoch (`img.chefkoch-cdn.de` 403) and Joy of Baking (0 pictures, `picturesFailed=1`); "Retry pictures" cannot succeed. `ImageDownloader` already sends a browser UA + `Referer` (`core/web/…/ImageDownloader.kt:79-84`), so the block is TLS/cookie based. **Fix:** forward the WebView's cookies (`CookieManager.getInstance().getCookie(url)` as `Cookie` header) and, as a last resort, fetch the bytes inside the page (`evaluateJavascript` → `fetch(url).blob()` → base64, same-origin so cookies and fingerprint match) when OkHttp returns 401/403; keep the hero from `og:image` as a second try.
2. **(P1) Single-blob `recipeInstructions` / dash-joined `recipeIngredient` → model runs and loses content or echoes the blob** (Directo al Paladar dropped the 15-minute cook and the serving tail; receptes.cat kept 1 ingredient). Cause: `isComplete` (`RecipeKeeperClipConfig.kt:353-354`, `MIN_COMPLETE_STEPS = 2` / `MIN_COMPLETE_INGREDIENTS = 3`, `:470-471`) only counts items; `SchemaOrgRecipeMapper.splitTextSteps` (`:189`) splits only inline numbering, not sentences, and `flattenStrings` (`:132`) splits only on `\n`. **Fix:** (a) in the mapper, when a single instruction string is > ~200 chars with no numbering, split it into sentences (keep "…, y ponemos …" clauses intact) deterministically, and split an ingredient line on `-`/`•`/`;` when it contains ≥ 3 quantity tokens; (b) then `isComplete` is true and the model is skipped (and cannot drop text); (c) add a `RecipeKeeperClipConfigTest` fixture for both shapes.
3. **(P1) Text-tier recipes can have their method replaced by a two-line paraphrase** (Smitten). The model is run with a 2-step summary-like output while the page has 3 long paragraphs; `accept` (`RecipeKeeperClipConfig.kt:370-374`) accepts any item with ≥ 2 steps. **Fix:** after parsing a TEXT candidate, compare against the section text: if the parsed steps contain < ~60 % of the section's instruction words (or fewer steps than instruction paragraphs), prefer a deterministic text fallback (paragraphs under the "Directions/Instructions/Method/Elaboració/Zubereitung/Préparation" heading as steps) and offer the model output only as the ingredients/title source. At minimum raise `maxOutputTokens` effects aside — the prompt in `RecipeKeeperPromptBuilder.kt` should say "copy every instruction, do not summarise".
4. **(P2) Page notes are never captured on the deterministic path** (`SchemaOrgRecipeMapper.kt:63` `notes = null`); WPRM/Tasty/Mediavine put Notes outside JSON-LD (Budget Bytes, Skinnytaste, Love & Lemons, Nigella "Make ahead / store"). **Fix:** in `detectStructured`, read the snapshot's heading sections for a heading matching `notesWord` (`RecipeKeeperClipConfig.kt:494`) and attach its text (≤ 600 chars) as `notes` in `fallback()`/the skip-model path.
5. **(P2) Near-duplicate pictures pre-checked and saved** (receptes.cat: 400 px + 500 px of the same photo; Love & Lemons brownies: 3 near-identical crops pre-checked; Marmiton/Skinnytaste/Budget Bytes 3 pictures). `rankPictures` dedupes by `TextCleaner.urlKey` (`RecipeKeeperClipConfig.kt:431`, `TextCleaner.kt:50`), which only strips `#`/`?`. **Fix:** also key on the file stem with size/thumb path segments and WP suffixes stripped (`-\d+x\d+`, `/thumbphoto/\d+/`, `/thumbmobi/`, `/crop-\d+x\d+/`), keeping the largest `naturalWidth`; only pre-check one image per stem.
6. **(P2) "2 recipes found" for a single recipe** (receptes.cat: JSON-LD + microdata of the same recipe). `core/web/src/main/assets/webclipper/quickscan.js` sums JSON-LD + microdata + RDFa counts; the full `detect()` later dedupes. **Fix:** count JSON-LD first and use microdata/RDFa only when JSON-LD found nothing, or compare names; add a quickscan test with a page carrying both.
7. **(P3) Servings keep the whole yield sentence** (Joy of Baking: "about 4 - 4 1/2 inch … waffles, or …"; Sally's "16 XL cookies or 20 medium/large cookies"; Nigella "about 12 slices"). **Fix:** show at most the first sentence / 40 chars in the chip, keep full text in the detail meta.
8. **(P3) Glued quantity+unit from source markup** ("2tablespoon", "1teaspoon", "1level tsp", "3tbsp", "1rovell d'ou", "150grs"). `TextCleaner.tidyNumbers` (used at `SchemaOrgRecipeMapper.kt:84`) fixes decimals but does not insert the space. **Fix:** regex `(\d)([A-Za-zà-ÿ]{1,12})\b` → `$1 $2` for known unit tokens in the ES/CA/EN/DE/FR/IT unit lists.
9. **(P3) Newlines inside a JSON-LD step become separate steps, including promo lines** (King Arthur "To see a full visual walkthrough…"). `flattenStrings`/`splitTextSteps` (`SchemaOrgRecipeMapper.kt:132,141,189`): join a split step into the previous one when it starts lower-case or matches `^(to see|watch|see our|click|video)`; drop steps that are only a video/CTA sentence.
10. **(P3) TEXT-tier cook/total time are inferred** (Nigella `cook = 60`, Joy of Baking `cook = 5`, `total = 15` = prep only). Prompt should not invent times: allow `cook`/`total` only when the page states them (`"Cook time"`, `"Total time"`, ISO), else null.
11. **(P3) Joy of Baking host stored as `m.joyofbaking.com`** (mobile redirect) — the library subtitle shows the `m.` host; strip a leading `m.`/`mobile.` in `TextCleaner.host` (`TextCleaner.kt:56`).

Observations (no action): consent walls (Sourcepoint, cuina.cat) do not block detection or capture — the FAB badge and clip work *through* the wall; `No recipe found` on a paywall / 404 behaves correctly, with `Extract anyway` available; ingredient fractions (½, ¼, 1/2, ⅔) survive on every site that has them (BBC, Love & Lemons, Nigella, King Arthur); no `½` loss on WPRM sites; Catalan, Spanish, German, French and Italian pages extract without any heading-recognition problem on the JSON-LD path.
