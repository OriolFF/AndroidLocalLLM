Read `docs/plans/briefs/features-common.md` (rules 0–3, worktree, commit/report). Context: users see "No recipe found on this page" on real recipe pages because the text-tier detector in `app/recipekeeper/.../clip/domain/RecipeKeeperClipConfig.kt` (`quantityLine`, `ingredientsWord`, `instructionsWord`, `MIN_QUANTITY_LINES`, `detectText`) only knows English units well, and the page sections come from h1–h3 only (`core/web/src/main/assets/webclipper/capture.js`). The model (whole-page "Extract anyway") then finds the recipe fine.
**You own:** `app/recipekeeper/src/main/kotlin/com/llmlocal/recipekeeper/clip/**` (+ its tests), `core/web/src/main/assets/webclipper/capture.js` + `core/web/tools/capture-harness/**` + `core/web/src/test/**`, `feature/webclipper/src/main/res/values/strings_webclipper.xml`, `feature/webclipper/src/main/kotlin/com/llmlocal/feature/webclipper/presentation/{WebClipperLabels.kt,ui/NothingDetectedSheet.kt}`, `app/recipekeeper/src/main/res/values/strings_webclipper.xml`, `app/recipekeeper/.../clip/presentation/RecipeKeeperClipperLabels.kt`, `feature/webclipper/src/test/**`.
